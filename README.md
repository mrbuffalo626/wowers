# Student Supplies Ordering System

A small PHP and Bootstrap cash-ordering app for six hard-coded school supplies. Cart, payment errors, and completed receipts are stored in the PHP session; no database or package installation is required.

## Run with XAMPP

1. Copy this folder into `C:\xampp\htdocs` if it is not already there.
2. Start Apache in the XAMPP Control Panel.
3. Open `http://localhost/examers/StudentSuppliesOrderingSystem/`.

## Run with PHP's built-in server

From this folder, start the server with `php -S localhost:8000` and open `http://localhost:8000`.

Bootstrap 5.3.3 is loaded from jsDelivr, so an internet connection is needed for the styling. The application itself is PHP session based.
